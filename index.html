Como trabalho

Uso Claude Code como parte do processo e transformei o que se repete em skills próprias. Cada uma virou um passo padrão, testado em projeto real.

skill · clone-website

Engenharia reversa de layout

Extrai assets, CSS e conteúdo seção por seção e reconstrói a página com agentes em paralelo. Base de vários sites deste portfólio.

skill · lead-handler-php

Captação de leads padrão

Backend PHP com SMTP, anti-spam sem CAPTCHA de terceiros, deduplicação, logs e passagem para o WhatsApp.

skill · subir

Deploy com travas

Compila, roda as checagens de qualidade, empacota e publica na Hostinger, sempre confirmando o domínio antes.

skill · seo

Auditoria de SEO

SEO técnico, local, schema, Core Web Vitals e presença em respostas de IA, com subagentes em paralelo.

skill · open-seo

SEO com dados reais

Volume, dificuldade, SERP, Google Maps e backlinks pela DataForSEO, com estimativa de custo antes de cada chamada.

skill · open-generative-ai

Imagem e vídeo com IA

Mais de 700 modelos (Flux, Kling, Veo, Seedance). Valida parâmetros e custo antes de gerar e salva no lugar certo do projeto.

skill · pagina-prompts-imagens

Página com prompt, formato, tamanho e nome de arquivo de cada imagem que o cliente gera no ChatGPT ou Gemini.

SCR Kitchens · loja Tray

Na loja Tray da SCR Kitchens, o botão de finalizar abre um formulário próprio e envia o pedido completo para o WhatsApp de vendas. Se o script falhar, o checkout nativo segue funcionando.

Ver no ar: scrkitchens.com.brTodos os projetos

O que eu construí

  • Lê os produtos pela API do carrinho do tema, com plano B pelo carrinho lateral
  • Mensagem com cliente, endereço via ViaCEP, produtos, quantidades, preços, links e subtotal
  • Liga e desliga por configuração, com modo de teste que mantém o checkout nativo
  • Diagnóstico da loja pela API pública: 855 produtos e 42 marcas
  • Melhorias no tema: preço De/Por, à vista e 12x, botão 'Negocie pelo WhatsApp' e seção de marcas
  • Achado: uma tag no GTM reescrevia os links de WhatsApp e apagava o produto da mensagem
